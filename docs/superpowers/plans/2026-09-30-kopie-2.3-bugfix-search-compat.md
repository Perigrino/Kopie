### Task 1: Remove DB queries from view bodies (~45 min)

**Root cause:** `MainView.filtered` (`MainView.swift:42-55`) runs `state.store.query` (SQLite + per-row decrypt) on every body pass; `detail` runs a second one (`MainView.swift:198`). Background clipboard captures re-render and reorder the list under the selection → sluggish clicks, selection appears not to move.

> **Deviation (executed):** thumbnails are NOT generated on a background task — `ThumbnailGenerator.resize` uses `NSImage.lockFocus`, a main-thread API. Instead, failed generation is memoized (`thumbGenFailed`) so a missing/corrupt image is never re-decoded during a row render; successful results were already cached.

**Files:**
- Modify: `Sources/Kopie/AppState.swift`
- Modify: `Sources/Kopie/UI/MainView.swift`

**Interfaces:**
- Produces: `AppState.mainItems: [ClipboardItem]` (`@Published`), `AppState.mainQuery: QueryFilter` (last applied filter), `AppState.refreshMain()` — re-runs the last main-window query. `MainView` reads only these.

**Steps:**

- [x] Step 1: In `AppState`, add:

```swift
@Published var mainItems: [ClipboardItem] = []
private var mainFilter = QueryFilter()

/// Re-runs the main-window query and republishes the result.
/// Called on store changes, filter changes, and (debounced) search changes.
func refreshMain() {
    mainItems = store.query(mainFilter)
}

/// Main-window query entry point: applies filter + search text, then refreshes.
func setMainQuery(_ filter: QueryFilter) {
    mainFilter = filter
    refreshMain()
}
```

- [x] Step 2: Call `refreshMain()` from `storeChanged()` and from `init` (after monitor setup), so the window is populated at launch and on every capture.

- [x] Step 3: In `MainView`:
  - Replace `filtered` body with a computed read of `state.mainItems`.
  - Replace `detail`'s `filtered.first(where:)` with `state.mainItems.first(where:)`.
  - Build the `QueryFilter` in a `private func applyFilter()` that calls `state.setMainQuery(f)`; call it from `.onChange(of: selection)` and a 0.2 s-debounced `.onChange(of: searchText)` (cancel prior `Task` via `@State private var searchDebounce: Task<Void, Never>?`).
  - Change `.onChange(of: filtered)` selection-guard to `.onChange(of: state.mainItems)` (same logic: if selected id vanished, select first).
- [x] Step 4: Thumbnails: in `AppState.thumbnail(for:)` (`AppState.swift:29-51`), move the `generateThumbnailIfNeeded` fallback off the main thread:

```swift
// inside thumbnail(for:), replacing the sync generation block:
if let imageRel = item.imageRelPath, !thumbGenInFlight.contains(imageRel) {
    thumbGenInFlight.insert(imageRel)
    let hashHex = (imageRel as NSString).lastPathComponent.replacingOccurrences(of: ".png", with: "")
    Task.detached(priority: .utility) { [weak self] in
        let rel = self?.thumbGenerator.generateThumbnailIfNeeded(imageRelPath: imageRel, hashHex: hashHex)
        await MainActor.run {
            guard let self else { return }
            self.thumbGenInFlight.remove(imageRel)
            if let rel, let img = self.writer.loadThumb(relPath: rel) {
                Self.thumbCache.setObject(img, forKey: rel as NSString)
            }
            self.thumbBump += 1   // @Published var thumbBump = 0 → re-render rows
        }
    }
}
return nil
```
  Add `private var thumbGenInFlight: Set<String> = []` and `@Published var thumbBump = 0`.

- [x] Step 5: Verify: `swift test` passes; `./scripts/build.sh debug` warning-free; `npm run dev` → click rows rapidly, arrow through list, background copies no longer reorder under the cursor.

New view in the same file:

```swift
/// Full-resolution image with the thumbnail shown while it loads.
private struct DetailsImage: View {
    @EnvironmentObject var state: AppState
    let item: ClipboardItem
    @State private var full: NSImage?
    var body: some View {
        ScrollView([.horizontal, .vertical]) {
            Group {
                if let full {
                    Image(nsImage: full).resizable()
                } else if let thumb = state.thumbnail(for: item) {
                    Image(nsImage: thumb).resizable()
                } else {
                    ProgressView().frame(maxWidth: .infinity, minHeight: 200)
                }
            }
            .aspectRatio(contentMode: .fit)
            .frame(maxWidth: .infinity)
            .clipShape(RoundedRectangle(cornerRadius: 12, style: .continuous))
        }
        .task(id: item.id) {
            full = nil
            full = await Task.detached(priority: .userInitiated) {
                state.fullImage(for: item)
            }.value
        }
    }
}
```
