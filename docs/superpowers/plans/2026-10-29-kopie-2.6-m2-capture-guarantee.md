# M2 Capture-Guarantee Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. That skill is not installed in this environment — emulate it: one fresh subagent per task, inline diff review between tasks, every task gated on `swift test` + `swift build -c release` before its commit.

**Goal:** Kopie never silently loses a copy: every pasteboard change either lands in history or is surfaced by a missed-copies badge that reconcile repairs; our own writes never re-capture; background reads can honor the macOS 15+ pasteboard-prompt contract; and rapid multi-copies can optionally render as one grouped entry.

**Architecture:** `ClipboardMonitor` becomes a fully injectable, test-observable capture source (changeCount provider closure, serial background read queue with main-thread ordering, count-based own-write filter, delta>1 → anomaly signal, one-tick read retry, reconcile). Decision logic stays pure and unit-tested in KopieCore; the app layer (`AppState`) owns wiring and published badge state; the popover/main window render day groups with optional `CopyGrouper` burst entries inside each day group. Grouping is query-time only — **no schema migration**; toggling renders both ways over the same rows.

**Tech Stack:** Swift 6 (swift-tools-version 6.2), SwiftPM, AppKit + SwiftUI, SQLite3 (existing), Swift Testing for new tests (matching the M1 plan's convention), existing XCTest suite untouched.

```swift
import Foundation
import AppKit

/// Observes the system pasteboard's change count and turns every reported
/// change into exactly one `read()` → `handle()` pipeline run.
///
/// Capture guarantee (S-010/S-011/S-012):
/// - Every observed delta either lands a capture or is *surfaced* as a miss —
///   never silently dropped. Deltas > 1 are accounted in `missedCount`
///   (intermediate contents are unrecoverable; the newest state is captured).
/// - A failed read gets exactly one retry on the next tick; after that it
///   counts as a miss via `onAnomaly`.
/// - Our own pasteboard writes never re-capture: write sites call
///   `noteSelfWrite()` after the write; the filter is count-based
///   (`observedCount <= lastSelfWriteCount` skips), which survives multiple
///   rapid user changes after our write. `beginSuppression()` is the legacy
///   *pre-write* signal kept as a second belt.
/// - Reads NEVER execute unless the injected `readGate` allows it (S-013:
///   the macOS 15+ pasteboard-prompt contract — reads tied to user intent).
///   A gated skip is intentional and never surfaces as an anomaly.
///
/// Threading: `tick()` stays on the main run loop (Timer). The `read()`
/// runs on a private serial queue (byte-heavy clips don't block the main
/// loop), and `handler` is invoked back on the main thread in queue order —
/// `ClipStore` writes stay main-thread until S-031 (M4) adds FULLMUTEX, and
/// the serial queue preserves capture order across the hop.
public final class ClipboardMonitor: @unchecked Sendable {
    // Reads only the integer — the only thing we need from the pasteboard here.
    private let readChangeCount: () -> Int
    private let read: () -> CapturedContent?
    private let handle: (CapturedContent) -> Void
    private let readGate: (() -> Bool)?
    private let captureQueue = DispatchQueue(label: "com.kopie.capture", qos: .userInitiated)

    private var timer: Timer?
    private var lastCount: Int
    private var lastSelfWriteCount: Int?
    private var pendingSuppression = 0        // legacy pre-write signal (Task 2 keeps one writer site)
    private var pendingRetry = false
    private(set) var missedChanges: Int = 0

    /// Current accumulated missed changes. Grows monotonically; resets
    /// internally inside `reconcile()` (silently — no anomaly re-report).
    public var missedCount: Int { missedChanges }

    /// Fired on the caller-chosen thread whenever missedCount increases.
    public var onAnomaly: ((Int) -> Void)?

    public var isRunning: Bool { timer != nil }

    /// - Parameters:
    ///   - readChangeCount: injectable read of the pasteboard's changeCount
    ///     (production: `{ NSPasteboard.general.changeCount }`; tests: a closure
    ///     over a mutable integer).
    ///   - reader: produces a CapturedContent from the current pasteboard, or
    ///     nil when the board is empty/unreadable.
    ///   - handler: invoked on the main thread, in capture order.
    ///   - readGate: evaluated on the main thread before any read; returning
    ///     false skips the capture intentionally (S-013).
    public init(readChangeCount: @escaping () -> Int,
                reader: @escaping () -> CapturedContent?,
                handler: @escaping (CapturedContent) -> Void,
                readGate: (() -> Bool)? = nil) {
        self.readChangeCount = readChangeCount
        self.read = reader
        self.handle = handler
        self.readGate = readGate
        self.lastCount = readChangeCount()
    }

    public func start() {
        guard timer == nil else { return }   // idempotent: already running
        lastCount = readChangeCount()
        timer = Timer.scheduledTimer(withTimeInterval: Self.tickInterval, repeats: true) { [weak self] _ in
            self?.tick()
        }
        RunLoop.main.add(timer!, forMode: .common)
    }

    public func stop() {
        timer?.invalidate()
        timer = nil
    }

    /// Poll cadence. 0.15s keeps up with copies ≥ 300ms apart (S-010 harness)
    /// while idling at one integer compare per tick.
    static let tickInterval: TimeInterval = 0.15

    /// Legacy pre-write suppression: bump immediately before our own
    /// pasteboard write on the same run-loop turn.
    public func beginSuppression() { pendingSuppression += 1 }

    /// Count-based own-write filter (S-011): call once AFTER our own
    /// pasteboard write, on the main thread.
    public func noteSelfWrite() { lastSelfWriteCount = readChangeCount() }

    /// Forced read of the current board state, for reconcile-on-open (S-012).
    /// Clears `missedChanges` without raising `onAnomaly` — the popover owns
    /// badge dismissal for display purposes.
    public func reconcile() {
        pendingRetry = false
        missedChanges = 0
        lastCount = readChangeCount()
        guard readGate?() ?? true else { return }
        if let content = read() {
            let handle = self.handle
            captureQueue.async { handle(content) }   // read already done on THIS thread (caller thread = main)
        }
    }

    public func tick() {
        let n = readChangeCount()
        if n == lastCount {
            if pendingRetry { retryRead() }
            return
        }
        // A. own-write filter — count-based, survives user changes above our write.
        if let own = lastSelfWriteCount, n <= own { lastCount = n; return }
        // B. legacy suppression — the one write that is about to happen on
        //    this same run-loop turn.
        if pendingSuppression > 0 {
            pendingSuppression -= 1
            lastCount = n
            return
        }
        let delta = n - lastCount
        if delta > 1 {
            // Multiple changes since the last tick: intermediate contents are
            // gone (the board only holds the newest); surface, don't stay silent.
            pendingRetry = false
            missedChanges += delta - 1
            onAnomaly?(missedChanges)
        }
        lastCount = n
        guard readGate?() ?? true else { return }
        readNow()
    }

    private func readNow() {
        let c = read()
        if let content = c {
            pendingRetry = false
            let handle = self.handle
            captureQueue.async { handle(content) }
        } else if pendingRetry {
            pendingRetry = false
            missedChanges += 1
            onAnomaly?(missedChanges)
        } else {
            pendingRetry = true     // one retry on the next tick
        }
    }

    private func retryRead() {
        pendingRetry = false
        if let content = read() {
            let handle = self.handle
            captureQueue.async { handle(content) }
        } else {
            missedChanges += 1
            onAnomaly?(missedChanges)
        }
    }
}
```

- `reconcile()` performs its `read()` on the **caller's** thread (main) — it is not dispatched to `captureQueue` because the caller usually calls it while the popover opens and we want the newest content on the way to the store immediately; the queue hop is only needed when preventing main-thread stutter, which reconcile's single read is not about. Keep exactly as written.
- This file is in KopieCore, so `NSPasteboard` only appears in doc comments — the module stays AppKit-light (it imports AppKit already; do not remove that import).
- The old class doc comment (lines 1-7) is replaced by the new one above.

import Foundation

/// Tracks "the user touched this app recently" for the capture read gate
/// (S-013). On macOS 15+/26, periodic pasteboard reads behind the user's
/// back trigger the system's periodic "app read your clipboard" prompts.
/// We therefore only read when a session interaction is recent, unless the
/// user opts the app back into always-on capture via settings
/// (`captureOnlyWhileInteracting` == false is the default: opted-in).
public struct CaptureRecency: Sendable {
    /// An interaction counts toward reads for this long, in seconds.
    public let activeWindow: TimeInterval
    private var lastActivity: Date?
    private var touchedAnyTime: Bool

    public init(activeWindow: TimeInterval = 90) {
        self.activeWindow = activeWindow
        self.lastActivity = nil
        self.touchedAnyTime = false
    }

    public mutating func touch(_ now: Date = .now) {
        lastActivity = now
        touchedAnyTime = true
    }

    /// True when the app may read the pasteboard on this tick: touched
    /// within `activeWindow` at `now` (inclusive boundary).
    public func mayRead(_ now: Date = .now) -> Bool {
        guard touchedAnyTime, let last = lastActivity else { return false }
        return now.timeIntervalSince(last) <= activeWindow
    }
}

```swift
import Foundation

/// Query-time grouping of rapid multi-copies. No schema change: groups are
/// computed when a list renders, so toggling never rewrites history.
public struct CopyGroup: Equatable, Sendable {
    /// The newest member — the row the group renders as.
    public let leaderID: Int64
    /// Newest-first; member[0] is the leader.
    public let members: [ClipboardItem]
}

public enum GroupedEntry: Equatable, Sendable {
    case single(ClipboardItem)
    case group(CopyGroup)

    /// The item this entry renders as (single item, or group leader).
    public var payload: ClipboardItem {
        switch self {
        case .single(let item): return item
        case .group(let g): return g.members[0]
        }
    }
}

public enum CopyGrouper {
    /// Two copies within this many seconds of each other (chained) belong to
    /// one burst. Chain rule: each member is compared to the previous member,
    /// not the leader, so a 6-copy burst 1.5s apart stays one group.
    public static let defaultWindow: TimeInterval = 2.0

    /// Collapses rapid multi-copy runs. `items` arrive newest-first (the
    /// store's query order). Callers pass one day's items so bursts never
    /// straddle day headers.
    ///
    /// Exempt rows never absorb into a group and never chain a burst over:
    /// pinned (kept as its own "Pinned" section upstream), favorited,
    /// and sensitive (masked) clips always render as single rows.
    public static func group(_ items: [ClipboardItem],
                             window: TimeInterval = defaultWindow) -> [GroupedEntry] {
        var out: [GroupedEntry] = []
        var burst: [ClipboardItem] = []
        var lastAddedDate: Date?

        func sameSource(_ a: ClipboardItem, _ b: ClipboardItem) -> Bool {
            // Two unattributed clips count as the same "unknown" origin —
            // that reading matches the "burst, same app" intent.
            return a.sourceApp == b.sourceApp
        }

        func flush() {
            if burst.count >= 2 {
                let members = burst
                out.append(.group(CopyGroup(leaderID: members[0].id, members: members)))
            } else {
                for single in burst { out.append(.single(single)) }
            }
            burst = []
            lastAddedDate = nil
        }

        for item in items {
            let exempt = item.isPinned || item.isFavorite || item.isSensitive
            let chains = burst.count > 0
                && lastAddedDate.map { $0.timeIntervalSince(item.createdAt) <= window } ?? false
                && sameSource(burst[0], item)
            if exempt {
                flush()
                out.append(.single(item))
                continue
            }
            if chains {
                burst.append(item)
                lastAddedDate = item.createdAt
            } else {
                flush()
                burst = [item]
                lastAddedDate = item.createdAt
            }
        }
        flush()
        return out
    }
}
```
